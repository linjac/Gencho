# Multi-Table Audio Configuration

## How to Configure Multiple Tables

Edit the `tableConfigs` object in `simple-table.js` to configure different IR examples for each table:

```javascript
const tableConfigs = {
    'rir-generation-table': {
        name: 'RIR Generation',
        irExamples: [
            {
                name: 'Alcuin College',
                filename: 'ir_openair_alcuin_college_university_york__b-format__s2r1_spist_bform'
            }
            // Add more examples for this table...
        ]
    },
    'real-world-table': {
        name: 'RIR Generation on real-world recordings',
        irExamples: [
            // Different IR examples for this table...
        ]
    },
    'text-controllable-table': {
        name: 'Text-Controllable RIR Generation',
        irExamples: [
            // Different IR examples for this table...
        ]
    }
};
```

## Available Tables

1. **rir-generation-table** - RIR Generation (standard 2-row format)
2. **real-world-table** - RIR Generation on real-world recordings (standard 2-row format)
3. **text-controllable-table** - Text-Controllable RIR Generation (special 4-column format)

## Text-Controllable Table Structure

The text-controllable table has a special structure with 4 columns:
- **Dry Speech**: Clean speech audio (shown once per text prompt)
- **Text Prompt**: Text description of the desired acoustic space
- **Gencho IR**: Generated IR audio (3 variations per prompt)
- **Gencho Speech**: Reverberant speech using the generated IR (3 variations per prompt)

Each text prompt creates 3 rows showing different IR variations generated by Gencho.

## Speech File Selection

The system automatically finds the correct speech file for each IR by looking at the available files in the outofdomain folder. Each IR has a corresponding speech file that was used to create the reverberant examples.

The system uses a mapping based on the actual files in the folder:
- Alcuin College → f4_script1-00031-clean.wav
- Hotel Skalsky → m2_script1-00031-clean.wav  
- Central Hall → f8_script1-00030-clean.wav
- Creswell Crags → m2_script1-00031-clean.wav
- Heslington Church → m9_script1-00006-clean.wav

## Table Structure

Each IR example creates 2 rows:
1. **IR Row**: Shows the IR audio files (target + model outputs)
2. **Speech Row**: Shows reverberant speech (dry speech + reverberant versions)

## Features

- ✅ Simple configuration (just edit the array)
- ✅ Automatic speech file detection from IR filename
- ✅ Consistent audio control height (30px)
- ✅ Easy to add/remove examples
